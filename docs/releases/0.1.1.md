## Custom device names and memory

Worker groups can use a built-in `gpu_profile` as a template and override the
device name with `gpu_name` and per-card memory with `gpu_memory_gib`.
Both fields are optional and can be set independently; omitted or `null` values
inherit the template. Memory is a positive finite number of GiB, including
fractions, and is reported as whole bytes. `memory_gib` remains host RAM.

```yaml
worker_groups:
  - name_prefix: sim-custom
    count: 10
    gpu_profile: b300-288gb
    gpu_name: "My Test GPU"
    gpu_memory_gib: 144
    gpu_count: 8
```

Normal worker status reports and monitoring expose the same custom name and
capacity. Overrides do not mutate templates or other groups. Reserved VRAM is
validated against the effective capacity. Vendor, CUDA/CANN, architecture,
compute capability, driver/runtime versions, and power still come from the
template; renaming a card does not select a new architecture or backend.

Existing configurations continue to work. To apply changes, restart WorkerSim
while retaining its identity volume and worker names. No Server/UI modification
is required. Heartbeat, watch, and HTTP-client behavior are unchanged.

## Validation and limits

Regression tests cover YAML loading, partial/null overrides, fractional memory,
invalid names/capacities, reservation bounds, CUDA/CANN inheritance, group
isolation, and custom inventory/status/monitoring plus deployment and cleanup
against the protocol fixture. The full CI suite also retains 1000-Worker
protocol, PD, distributed, model-file, and native-communication checks.
The complete suite passed locally on Windows: **96 tests in 65.96 seconds**.
The publishing workflow pulls the image by digest and verifies `--version`
and validation of the custom GPU/NPU example inside that image.

These are protocol-fixture and image checks, not a new real-Server capacity or UI
acceptance. The previous release's real-Server 500/1000 stability limitations
remain; see the [scale report](https://github.com/pengjiang80/gpustack-workersim/blob/v0.1.1-gpustack2.3.1/docs/scale-1000-validation.md).
