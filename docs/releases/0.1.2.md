# WorkerSim 0.1.2

WorkerSim now generates the same Server load and drives the same recovery paths as a
native GPUStack 2.3.1 Worker, and its runtime metrics follow the native aggregator.

## Compatibility

| Component | Version |
|---|---|
| WorkerSim product/package | **0.1.2** |
| Supported GPUStack Server / Worker protocol | **2.3.1** |
| Protocol source commit | `458030e88718ce47bd31f7cdee9cbc8994a6760b` |
| Release tag | `v0.1.2-gpustack2.3.1` |

## Native Worker load and recovery

- **Orphan-workload sweep:** while a Worker has model workloads, an uncached
  `GET /v2/model-instances?page=-1` every 120 s, starting 15 s after startup.
- **Worker-side restart of ERROR instances:** 10 s loop, delay 10 s doubling to 300 s,
  uncached re-read, `restart_on_error` check, then `restart_count + 1` / `scheduled`.
  The delay resets once the instance serves again.
- **Runtime-metrics loop:** `GET /v2/workers/{id}` twice per pass when there are sources,
  `/v2/metrics/config` every 300 s, and a one-time `api_detected_backend_version` write
  for legacy instances.

## Version check

Like the native Worker, a Server version mismatch only logs a warning.
`server.allow_version_mismatch` is deprecated and ignored. WorkerSim registers
`worker_version: "v2.3.1"` and serves `/version`, matching a release build.

## Topology and device network

- `nvlink_domain_workers` (worker group): per-card `nvidia.com/gpu.clique` hints and
  Worker `topology_facts`.
- `kv_transfer_ifname` (worker group): reported verbatim.
- `network.npu_roce_cidr` (default `10.200.0.0/16`): per-NPU RoCE addresses with
  `network.status: up`, required by MindIE multi-node placement.
- Worker API adds `/readyz` and `/version`.

## Metrics

- Engines expose native vLLM, SGLang, MindIE, PD-router and SGLang-gateway families.
- The Worker normalizes them with the Server's `/v2/metrics/config` (vendored built-in
  fallback): native labels, version selectors, unit scaling, scrape status and the 30 s
  snapshot TTL. Model series appear after the native 30 s delay.
- Exposition headers follow `prometheus_client.generate_latest`.

**Behaviour changes:** model series no longer carry `workersim="true"` or
`exposition_scope="legacy"`; `/metrics/raw` uses each engine's native names.
Per-worker `workersim_*` series remain.

## Validation

110 regression tests pass. `scripts/native_contract.py` was run against unmodified
GPUStack v2.3.1 sources: `WorkerCreate` validates the new status fields, all 182 engine
families map identically, and normalized output matches the native aggregator sample
for sample (192 families). This is not a new real-Server capacity or UI acceptance.
